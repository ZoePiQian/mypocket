MyPocket 1.0.1 · 你的口袋管家。

作者：**Zoe Qian**。

## 本次改进

- 补充英文功能介绍、安装和使用步骤，完善社区目录展示信息。
- 查账、目录整理和回收站直接遍历所配置的财务目录，减少对整个笔记库的遍历。
- 凭证导入中断时，已经写入的文件会保留并提示位置，避免全库扫描和误删其他笔记引用的凭证。正常保存的账目和凭证关联方式不变。
- 清理冗余界面样式，明确手机视口高度的兼容分支，保留图表对齐和不支持新布局时的备用显示。
- 加入依赖锁文件及 Windows、Linux 构建比对，通过 GitHub Actions 生成发布文件及可验证的构建来源证明。

## 安装与更新

社区安装使用下方三个附件：`main.js`、`manifest.json`、`styles.css`。

手动安装可下载仓库中的 [MyPocket-1.0.1.zip](https://github.com/ZoePiQian/mypocket/raw/1.0.1/MyPocket-1.0.1.zip)，将解压后的 `local-finance-notes` 文件夹放入库的 `.obsidian/plugins/`。更新已有安装时仅替换三个程序文件，保留个人 `data.json` 和流水笔记，再重新加载插件。

## English

This maintenance release adds English installation and usage documentation, limits finance scans to the configured data folder, and improves CSS compatibility. If a receipt import is interrupted after writing a file, the file is retained and its location is reported instead of scanning unrelated notes or risking deletion. GitHub Actions compares Windows and Linux build output and attests the final release assets.
